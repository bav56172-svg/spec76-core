
# SPEC76 OS — SYSTEM GLOSSARY

---

# 🧠 1. ОБЩИЙ ПРИНЦИП

Этот документ является **единым источником терминов SPEC76 OS**.

Все модули системы обязаны использовать термины строго в соответствии с этим глоссарием.

---

# ⚙️ 2. БАЗОВЫЕ ТЕРМИНЫ СИСТЕМЫ

---

## 🟢 Task (задача)

Единица работы в системе SPEC76.

Содержит:
- описание действия
- статус выполнения
- связанный AI analysis (анализ)
- execution flow (поток выполнения)

---

## 🟢 Project (проект)

Контейнер задач, объединённых общей целью.

Используется для:
- структурирования работы
- управления Kanban (канбан) доской
- группировки execution flow (поток выполнения)

---

## 🟢 Execution (выполнение)

Процесс реального выполнения задачи в системе SPEC76.

Включает:
- AI analysis (анализ)
- Agent validation (проверка агентами)
- Human approval (подтверждение человеком)
- Real-world action (реальное действие)

---

## 🟢 Agent (агент)

Автономный логический модуль проверки и анализа.

Типы агентов:

- QA Agent (агент качества)
- Safety Agent (агент безопасности)
- Compliance Agent (агент соответствия правилам)
- Data Integrity Agent (агент целостности данных)

---

## 🟢 Stream (поток)

Realtime (реальное время) передача событий от backend к UI.

Используется для:
- Agent feedback (обратная связь агентов)
- Execution tracking (отслеживание выполнения)

---

## 🟢 Memory (память)

Система хранения:

- прошлых решений
- результатов агентов
- истории выполнения задач

---

## 🟢 Rule Engine (движок правил)

Система логики, которая определяет:

- как агенты принимают решения
- какие проверки выполняются
- какие условия считаются критичными

---

## 🟢 Human-in-the-loop (человек в контуре)

Механизм, при котором человек подтверждает:

- критические действия
- рискованные решения
- финальные этапы execution

---

## 🟢 Kanban (канбан)

UI система управления задачами через колонки:

- Todo (в работе)
- In Progress (в процессе)
- Done (завершено)

---

# 🧠 3. ПРОЦЕССНЫЕ ТЕРМИНЫ

---

## 🟢 AI Analysis (анализ AI)

Разбор задачи системой искусственного интеллекта:

- декомпозиция
- планирование
- оценка сложности

---

## 🟢 Agent Feedback (обратная связь агентов)

Результаты работы агентов в реальном времени:

- status (статус)
- message (сообщение)
- decision (решение)

---

## 🟢 Execution Flow (поток выполнения)

Полная цепочка:

Task → AI → Agents → Human → Execution → Memory

---

## 🟢 Event (событие)

Единичное сообщение в Stream (потоке), описывающее состояние системы.

---

# 🧠 4. СИСТЕМНЫЕ ПРАВИЛА

---

## 🟢 1. Термины неизменны

Если термин зафиксирован в glossary — он не переопределяется в коде.

---

## 🟢 2. Один термин = одно значение

Нет альтернативных смыслов внутри системы.

---

## 🟢 3. English + Russian обязательно

Все термины используются в формате:

> English term (русский перевод)

---

## 🟢 4. Glossary является источником истины

Любой новый модуль обязан:

- проверять соответствие glossary
- не вводить новые термины без фиксации
