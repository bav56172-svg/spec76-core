# UX Gate — Проверка удобства

Перед завершением каждого пользовательского экрана проверить:

- понятно ли основное действие за пять секунд;
- нет ли инженерных терминов в пользовательском интерфейсе;
- показаны ли только необходимые действия;
- можно ли сократить количество полей;
- есть ли понятное состояние ошибки;
- работает ли сценарий на мобильном экране;
- не требуется ли инструкция для первого действия.
