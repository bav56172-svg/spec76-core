Для проекта масштаба СпецТехника76 основной способ сократить бюджет — не нанимать сразу полноценную команду из 6–8 человек, а заменить часть функций AI-агентами и low-code инструментами.

Классическая команда и стоимость: Product Manager 120–200 тыс ₽/мес; UX/UI Designer 80–150 тыс ₽/мес; Frontend Developer 150–250 тыс ₽/мес; Backend Developer 150–300 тыс ₽/мес; QA 60–120 тыс ₽/мес; SEO 50–150 тыс ₽/мес; Контент-менеджер 40–80 тыс ₽/мес. За MVP классическим способом легко уйдёт 1,5–3,5 млн ₽. С использованием AI можно снизить бюджет MVP до 300–800 тыс ₽.

## 1. AI для проектирования (вместо Product Manager + аналитика)

- **ChatGPT**: подготовка PRD; ТЗ; User Story; CJM; API-спецификаций; SQL-схем.
- **Claude**: особенно силён в больших документах, архитектуре, бизнес-логике. Использовать как второго архитектора.

## 2. AI для UX/UI (вместо UX-дизайнера на MVP)

- **Figma AI**: генерирует wireframes; карточки; формы; dashboard.
- **Lovable**: по описанию создаёт интерфейсы; React-приложения; формы; кабинеты. Для MVP один из самых сильных вариантов.

## 3. AI для фронтенда

- **Cursor AI**: практически обязателен. Генерирует Next.js, TypeScript, компоненты, API-клиенты. Экономия до 50–70% времени фронтенд-разработчика.
- **GitHub Copilot**: хорошо дополняет Cursor.

## 4. AI для backend

**Cursor + Claude** могут генерировать NestJS, PostgreSQL, Prisma, REST API, JWT — до 70–80% шаблонного backend-кода.

## 5. AI для базы данных

**Supabase** — серьёзная рекомендация для MVP. Сразу даёт PostgreSQL, авторизацию, файлы, realtime, роли. Может заменить месяцы backend-разработки.

## 6. AI для чата (вместо собственной разработки на MVP)

**Supabase Realtime** или **Stream Chat** — переписка, вложения, уведомления, мобильность без написания сложного мессенджера.

## 7. AI для SEO

Самая большая экономия для СпецТехника76. **ChatGPT + автоматизация** генерирует title, description, H1, тексты категорий и городов (например: «Экскаваторы в Ярославле», «Самосвалы в Рыбинске», «Автокраны в Ростове Великом») — тысячи SEO-страниц автоматически. **Ahrefs/Semrush** — для сбора запросов.

## 8. AI для Медиацентра

Очень сильная точка автоматизации. **n8n** связывает сайт, Telegram, VK, RSS, MAX (при наличии API). Сценарий: новое объявление → ChatGPT пишет пост → Telegram → VK → RSS → SEO-страница, практически без участия человека.

## 9. AI для модерации объявлений

**OpenAI API** проверяет спам, дубли, мошенничество, запрещённый контент. Экономия на модераторах.

## 10. AI для поддержки

**AI-оператор** на базе ChatGPT API + Telegram Bot + MAX Bot отвечает: как разместить объявление; как оплатить; как откликнуться на заявку.

## 11. AI для продаж (после запуска)

**AI SDR** на базе ChatGPT API + Telegram + Email автоматически приглашает компании региона с презентацией открытых категорий и партнёрских статусов.

## Рекомендуемый стек MVP

- Frontend: Next.js, TypeScript, Tailwind.
- Backend: Supabase.
- Поиск: PostgreSQL Full Text Search, OpenSearch позже.
- AI: ChatGPT, Claude, Cursor.
- Автоматизация: n8n.
- Дизайн: Figma AI, Lovable.
- Чат: Supabase Realtime.
- Платежи: ЮKassa, СБП.

**Оценка бюджета**: классическая разработка MVP — 1,5–3,5 млн ₽; AI-first MVP — 300–800 тыс ₽. Срок запуска: 6–10 недель при одном сильном full-stack разработчике + AI-инструментах.

Рекомендованная архитектура: **Next.js + Supabase + Cursor + Claude + ChatGPT + n8n** — позволяет запустить весь каталог, биржу заявок, медиацентр, партнёрскую программу и SEO-платформу без большой команды, с возможностью масштабирования после достижения 300+ компаний и 3000+ объявлений.
