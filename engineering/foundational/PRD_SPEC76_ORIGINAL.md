## 1. Описание продукта

- **Название**: СпецТехника76
- **Тип продукта**: B2B / B2G маркетплейс услуг спецтехники
- **Регион запуска**: Ярославская область
- **Основная ценность**: объединение в единой системе каталога услуг спецтехники, биржи заявок, медиацентра продвижения, рейтингов компаний, внутреннего чата, партнёрской программы.

## 2. Роли пользователей

- **Гость**: просмотр каталога; просмотр компаний; просмотр заявок; поиск и фильтрация.
- **Заказчик**: создание заявок; чат с компаниями; избранное; история запросов; отзывы.
- **Компания**: публикация объявлений; отклики на заявки; управление профилем; чат; аналитика.
- **Представитель района**: + районная страница; привлечение компаний; публикации района.
- **Официальный партнёр региона**: + приоритет в выдаче; расширенное продвижение; брендирование.
- **Генеральный партнёр**: максимальный уровень привилегий.
- **Модератор**: проверка объявлений; проверка заявок; управление отзывами.
- **Администратор**: полный доступ.

## 3. Ключевые пользовательские сценарии

**Сценарий 1 — Компания публикует объявление**: регистрация → заполнение профиля → создание объявления → загрузка фото → выбор тарифа → оплата → модерация → публикация → автопубликация через Медиацентр.

**Сценарий 2 — Заказчик создаёт заявку**: создание заявки → выбор категории техники → указание бюджета → публикация → авторассылка компаниям → получение предложений → выбор исполнителя.

**Сценарий 3 — Общение в чате**: открытие диалога → обмен сообщениями → передача файлов → обсуждение условий → закрытие сделки.

## 4. Экраны системы

- **Главная**: поиск; категории; последние объявления; последние заявки; партнёры; преимущества; CTA.
- **Каталог объявлений**: поиск; фильтры; сортировка; карта; избранное.
- **Карточка объявления**: галерея; характеристики; стоимость; рейтинг; отзывы; чат; контакты.
- **Биржа заявок**: список заявок; фильтры; статус заявок; кнопки отклика.
- **Карточка заявки**: описание; бюджет; сроки; предложения компаний.
- **Кабинет компании**: Дашборд; Объявления; Заявки; Чат; Финансы; Медиацентр; Аналитика.
- **Кабинет заказчика**: Заявки; Избранное; Чаты; История.
- **Страница компании**: профиль; рейтинг; парк техники; кейсы; отзывы.
- **Страница партнёров**: Генеральный партнёр; Официальные партнёры; Представители районов.


## 6. API-спецификация (оригинальное предложение)

```
Авторизация:   POST /api/auth/register, /login, /logout
Компании:      GET /api/companies, GET /api/company/{id}, POST /api/company, PUT /api/company/{id}
Объявления:    GET /api/ads, GET /api/ads/{id}, POST /api/ads, PUT /api/ads/{id}, DELETE /api/ads/{id}
Заявки:        GET /api/requests, POST /api/requests, GET /api/requests/{id}, POST /api/requests/{id}/offer
Чат:           GET /api/chats, POST /api/messages, GET /api/messages
Платежи:       POST /api/payments, GET /api/payments/history
Медиацентр:    POST /api/publications, GET /api/publications
```

## 7. Интеграции

- **Платежи**: ЮKassa; СБП.
- **Социальные сети**: Telegram Bot API; VK API; MAX API (при наличии публичного API).
- **Уведомления**: Email; SMS; Push.

## 8. Нефункциональные требования

- Производительность: загрузка страниц ≤ 2 сек.
- Доступность: 99,5%.
- Адаптивность: Mobile First.
- Безопасность: JWT; RBAC; HTTPS; защита от спама; защита от ботов.

## 9. Оценка разработки (оригинальная, по классической модели найма)

- **MVP** (каталог, объявления, компании, поиск, SEO, кабинеты): 2–3 месяца, 600 000–1 200 000 ₽.
- **Версия 2.0** (Биржа заявок, чат, рейтинги): 1–2 месяца, 400 000–800 000 ₽.
- **Версия 3.0** (Медиацентр, Telegram, VK, MAX, аналитика): 1–2 месяца, 300 000–700 000 ₽.
- **Полный проект**: 4–8 месяцев, 1,5–3,5 млн ₽. При собственной команде и поэтапном запуске MVP — выход на рынок через 8–12 недель.
