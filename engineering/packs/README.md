# Engineering Packs

Engineering Pack (инженерный пакет) — ограниченный инженерный результат, который поддерживает разработку платформы, но не занимает идентификатор продуктовой Operation (операции).

## Identifier Rules

- `OP-*` — продуктовые и платформенные операции Release (релиза).
- `EP-*` — инженерные пакеты разработки и инфраструктуры.

Один идентификатор не может обозначать два разных результата.

## Registry (реестр)

- `EP-021_SPEC76_BUILD_SYSTEM.md` — Build System (система сборки), завершён.
- `EP-023_SECURITY_RECOVERY.md` — Security and Recovery (безопасность и восстановление), в работе.
