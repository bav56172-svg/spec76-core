# Decision Memory Standard — Стандарт памяти решений

Решение может использоваться повторно, если:

- оно подтверждено владельцем;
- известен фактический результат;
- правило остаётся актуальным;
- текущий случай достаточно похож;
- риск автоматизации находится в разрешённых пределах.

Рекомендация обязана показывать:

- число похожих случаев;
- процент подтверждений;
- успешность;
- отмены;
- уровень риска;
- уровень уверенности;
- необходимость решения владельца.
