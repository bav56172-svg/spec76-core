# Knowledge Platform Architecture — Архитектура платформы знаний

## Компоненты

- Decision Memory (память решений);
- Case Library (библиотека случаев);
- Policy Library (библиотека правил);
- Lessons Learned (извлечённые уроки);
- Best Practices (лучшие практики);
- Regulatory Knowledge (нормативные знания);
- Knowledge Evolution (эволюция знаний).

## Главный принцип

Платформа сохраняет связь:

> ситуация → решение владельца → фактический результат.

## Управление качеством

AI Knowledge Curator (ИИ-куратор знаний) ищет дубли, противоречия и устаревшие правила, но не изменяет знания без утверждённой процедуры.
