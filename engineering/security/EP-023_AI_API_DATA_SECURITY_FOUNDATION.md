# Purpose (назначение)

Документ определяет архитектурную основу Data Security Foundation (основы безопасности данных) для будущего AI API.

Документ создаётся до создания Supabase migration (миграции Supabase).

Цели:

- защитить данные платформы;
- сохранить контроль человека;
- использовать существующую модель доступа;
- исключить небезопасные прямые операции AI API.

---

# Confirmed Context (подтверждённый контекст)

EP-023 AI API Recovery подтвердил:

- активных AI API routes нет;
- AI provider не подключён;
- таблица `ai_usage` отсутствует;
- RLS отсутствует для AI данных;
- реализация не начата.

EP-024 Platform Domain Foundation предоставил:

- profiles;
- companies;
- company_members;
- projects;
- существующую модель RLS.

---

# Data Model Decision (решение по модели данных)

Будущая сущность `ai_usage` является журналом использования AI Operations (ИИ-операций).

Назначение:

- контроль лимитов;
- аудит использования;
- защита от неконтролируемых операций.

Не хранить:

- полный текст пользовательских запросов;
- секреты;
- ключи поставщиков;
- внутренние данные проектов.

---

# Rollback Strategy (стратегия отката)

При невозможности безопасного завершения миграции:

- новая схема не переводится в активное использование;
- выполняется обратимая миграция согласно проверенной процедуре;
- существующие данные не удаляются автоматически;
- доступ пользователей сохраняется через предыдущую подтверждённую модель;
- результат отката фиксируется в инженерном журнале.
