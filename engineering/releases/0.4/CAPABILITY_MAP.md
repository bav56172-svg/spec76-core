# Capability Map — Release 0.4

| Код | Capability (возможность) | Основной результат |
|---|---|---|
| C-002 | Identity & Access (идентификация и доступ) | Пользователи, организации, роли, разрешения |
| C-005 | User Experience Platform (пользовательский опыт) | Простой интерфейс по ролям |
| C-003 | Workflow Platform (бизнес-процессы) | Управляемые маршруты и согласования |
| C-004 | Audit Platform (аудит) | Полная история значимых действий |
| C-007 | Knowledge Platform (знания) | Память решений, случаев, правил и результатов |
| C-006 | AI Operations Platform (ИИ-операции) | Специализированные агенты под контролем владельца |

## Зависимости

```text
Identity & Access
        ↓
User Experience
        ↓

        ↓

        ↓
```
