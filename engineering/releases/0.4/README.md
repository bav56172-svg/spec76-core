# Release 0.4 — Trusted Platform Operations

## Русское название

Доверенные платформенные операции.

## Цель

Сформировать безопасное, понятное пользователям и управляемое владельцем платформенное ядро SPEC76.

## Состав Capability (возможностей платформы)

- C-002 Identity & Access (идентификация и управление доступом).
- C-005 User Experience Platform (платформа пользовательского опыта).
- C-003 Workflow Platform (платформа бизнес-процессов).
- C-004 Audit Platform (платформа аудита).
- C-007 Knowledge Platform (платформа знаний).
- C-006 AI Operations Platform (платформа ИИ-операций).

## Порядок реализации

1. Identity & Access.
2. User Experience.
3. Workflow.
4. Audit.
5. Knowledge.
6. AI Operations.

ИИ-операции не запускаются до появления ролей, аудита, правил и управляемой памяти решений.
