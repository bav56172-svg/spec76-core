# Release Definition of Done — 0.4

Release 0.4 считается завершённым, если:

## Пользовательский опыт

- заказчик понимает основной экран без инструкции;
- основной сценарий заявки не перегружен внутренними модулями;
- исполнитель видит только рабочие действия своей роли;
- административная сложность скрыта от обычных пользователей;
- ключевые сценарии проверены по UX Checklist (чек-листу удобства).

## Безопасность

- роли и разрешения применяются на сервере и в RLS;
- критические действия требуют решения владельца;
- действия ИИ имеют ограниченные полномочия;
- все значимые решения аудитируются.

## Знания и ИИ

- решения владельца сохраняются структурированно;
- рекомендации содержат объяснение и уровень уверенности;
- автоматизация разрешена только для утверждённых низкорисковых правил;
- правила имеют версии и даты пересмотра.

## Качество

- ESLint проходит;
- TypeScript проходит;
- Production Build (производственная сборка) проходит;
- git diff --check проходит;
- миграции воспроизводимы;
- Engineering OS (инженерная операционная система) актуальна.
